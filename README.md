# Weather Pocket

## 배포 URL
> https://weatherpocket.vercel.app/

## GitHub Repository
> https://github.com/mynarne/weather_pocket

## 서비스 소개
Weather Pocket은 대한민국 전국 16개 광역자치단체 및 205개 시·군·구 단위로 날씨를 조회하고, 원하는 지역을 관심 지역(최대 5개)으로 관리할 수 있는 Next.js 기반 날씨 애플리케이션입니다.

2026년 7월 1일 공식 출범한 **전남광주통합특별시** 행정체계를 적용하였으며, 대시보드 형태의 **2열 Split 탐색 UI(좌측 세로 시·도 목차 + 우측 시·군·구 Compact Grid)**를 통해 최상의 사용성 및 시선 집중도를 제공합니다.

전국 행정구역 데이터를 선조회하지 않고 정적 데이터로 제공하여, 사용자가 최종 시·군·구를 선택하거나 등록된 관심 지역을 조회할 때만 날씨 API를 요청하는 온디맨드 구조를 가집니다.

## 주요 기능
1. **2열 Split 행정구역 탐색 UI (`RegionSelector`)**
   - **데스크톱/태블릿 (`md:` 이상)**: 좌측 260px 세로 광역자치단체 목차 패널 + 우측 1fr 시·군·구 Compact Grid
   - **모바일 (`md:` 미만)**: 상단 광역자치단체 선택 Native Select / 가로 칩 탭 UI + 하단 2열 시·군·구 Grid
   - **기본 선택**: 첫 진입 시 '서울특별시' 기본 선택 (기본 선택만 수행되며 **날씨 API 호출은 0회**)
   - **전남광주통합특별시 (27개 지역)**: 자치구(5), 시(5), 군(17) 유형별 컴팩트 구분 렌더링

2. **실시간 지역명 로컬 검색**
   - 시·도 명칭, 시·군·구 명칭 및 과거 검색어 alias(예: "광주 광산구", "전남 목포") 검색 지원
   - 검색 결과에는 항상 공식 통합 명칭(예: "전남광주통합특별시 광산구", "전남광주통합특별시 목포시")으로 정규화하여 출력

3. **선택한 지역의 현재 날씨 및 예보 (`/regions/[regionId]`)**
   - 최종 시·군·구를 선택했을 때 해당 지역 1곳의 날씨만 온디맨드로 조회
   - 현재 기온, 습도, 날씨 상태, 관측 기준 시각 및 7일간 주간 예보 제공
   - 유효하지 않은 지역 ID 접근 시 `notFound()` 기반 404 화면 처리

4. **관심 지역 등록 및 관리 (최대 5개)**
   - 별(★/☆) 버튼을 통한 관심 지역 등록 및 삭제
   - 관심 지역 최대 5개 제한 및 초과 등록 시 안내 메시지 제공
   - 구형 ID(`gwangju-gwangsan`, `jeonnam-mokpo`) 자동 마이그레이션(`jeonnam-gwangju-gwangsan`, `jeonnam-gwangju-mokpo`) 지원
   - Zustand persist 미들웨어를 통해 `localStorage`에 지역 ID만 저장

5. **부분 실패 대응 및 캐시 재검증**
   - 일부 외부 API 요청 실패 시 성공한 지역 카드는 정상 표시 (`Promise.allSettled`)
   - `revalidate: 900`을 통해 애플리케이션에서 15분 단위 캐시 재검증 정책 적용

## API 호출 전략

- **정적 행정구역 데이터 제공**: 전국 16개 광역자치단체 및 205개 시·군·구 목록과 대표 좌표는 `src/constants/regions.ts` 정적 데이터로 보관합니다. (행정구역 데이터 기준: 2026년 7월)
- **선조회 없는 지역 탐색**: 시·도 카드를 클릭하거나 시·군·구 목록을 렌더링할 때 날씨 API를 전혀 호출하지 않습니다. (API 0회)
- **최종 선택 시 1곳만 조회**: 사용자가 최종 시·군·구를 클릭하여 상세 페이지(`/regions/[regionId]`)로 이동했을 때 해당 좌표 1곳만 Open-Meteo API에 요청합니다.
- **관심 지역 온디맨드 페칭**: 관심 지역 화면에서는 등록된 관심 지역 ID(최대 5개)만 조회하며, 동일 지역 중복 요청을 방지합니다.
- **예측 가능한 요청 수**: 관심 지역 개수를 최대 5개로 제한하여 홈 화면 진입 시 API 요청량을 예측 가능한 범위로 유지합니다.

## 실행 방법

```bash
# 패키지 설치
npm install

# 정적 정밀 분석
npm run lint

# Vitest 단위 테스트 실행
npm run test

# 프로덕션 빌드 검증
npm run build
```
